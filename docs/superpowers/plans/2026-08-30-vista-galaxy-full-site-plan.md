# VISTA.IO × Galaxy 全站實作計畫

## 視覺落點

- Lane：資料／粒子智能型 WebGL 首頁，服務首購決策而非純展示。
- 色彩：Void `#050706`、Panel `#171B18`、Rule `#303731`、Ivory `#EDF2E6`、Coral `#FF624A`、Mint `#BFD8C5`。
- 排版：等寬展示字搭配無襯線內文；標題緊密、說明控制在 60–75 字元行寬。
- 版面：1152px 主容器、垂直容器線、細框深色面板、不對稱首頁排版。
- Signature：像資料星圖般緩慢旋轉的藍紫四旋臂與金色核心，象徵把分散房市資料收斂成決策方向。

## 實作步驟

1. 建立全站色彩、排版、容器線、焦點與表單 CSS token。
2. 更新 Galaxy 粒子顏色、密度、核心、相機與慢速旋轉參數。
3. 重構首頁與導覽，套用 VISTA.IO 式不對稱科技排版。
4. 改造問卷、推薦結果、台中行情、方法與資料、頁尾的深色資料介面。
5. 補齊表單錯誤關聯、展開控制與焦點可見性。
6. 執行建置與程式檢查；在桌機與手機驗證首頁與完整分析流程。
7. 提交、推送、儲存新版本並部署到既有私人 Sites。

## 驗證清單

- 首頁 Galaxy 可見、緩慢旋轉、無控制面板文字。
- 五步問卷可完成，驗證訊息可被輔助工具理解。
- 推薦結果可展開、情境按鈕可重算、外部連結保留。
- 行情與方法頁資料完整，文字與圖表在深色背景可讀。
- 390px 手機與桌機均無水平溢出；輸入文字至少 16px。
- 減少動態偏好、頁面隱藏及 WebGL context loss 都能安全處理。

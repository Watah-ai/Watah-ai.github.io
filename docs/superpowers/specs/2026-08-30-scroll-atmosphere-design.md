# 全站星空與捲動焦點光暈設計規格

## 目標

將 VISTA.IO 參考頁的暗黑、星點與區段光暈節奏整合到「好宅指南」所有主要內容頁。使用者向下捲動時，進入畫面中央的內容區域會柔和亮起，離開後回暗；亮度不得降低文字、圖表或操作元件的可讀性。

## 適用範圍

- 首頁：保留既有 3D Galaxy，將星空與光暈套用於首頁下半部的資料說明、流程與頁尾。
- 適居分析：問卷主區域及其外圍背景。
- 分析結果：預算區間、推薦清單、情境實驗室。
- 台中行情：行情圖表與解讀側欄。
- 方法與資料：分析步驟、正式資料來源、資料限制。
- 全站頁尾。

## 視覺系統

### 星空層

- 使用 CSS 徑向漸層建立低密度星點，不新增內頁 WebGL 或大型影像。
- 星點為低對比的象牙白、冷藍與少量珊瑚光點，主要集中於內容區域外圍。
- 星點位於內容與面板後方，不可穿透文字或控制元件造成閃爍。
- 手機降低星點密度與不透明度。

### 區段明暗節奏

- 主要內容區段使用 `#050706` 與 `#0b0e0c` 交錯，形成一黑一亮的基礎節奏。
- 非焦點區段保持低亮度，焦點區段只提高背景光感，不提高文字透明度。
- 分隔線仍使用既有薄線系統，避免新增厚重卡片框線。

### 焦點光暈

- 當區段進入視窗中央約 30%～70% 範圍時，套用低亮度藍灰色徑向光暈。
- 光暈中心位於區段中央偏上，色彩以冷藍灰為主，最高視覺不透明度約 12%～16%。
- 進入與離開使用約 700～900ms 的平滑透明度變化。
- 面板保持深色實底或高不透明度背景，正文與數字不受光暈干擾。
- 一次只允許一個主要區段成為焦點，避免整頁同時變亮。

## 元件與行為

### `ScrollAtmosphere`

- 提供固定的全站星空背景層。
- 使用 `IntersectionObserver` 觀察具有 `data-scroll-focus` 的主要區段。
- 選擇最接近視窗中央且正在相交的區段，設定 `data-scroll-active="true"`。
- 元件卸載或頁面切換時解除觀察，避免殘留監聽器。

### `scroll-focus-zone`

- 主要區段加入共用類別與 `data-scroll-focus` 屬性。
- 以偽元素承載光暈，內容層維持較高堆疊順序。
- 首頁 Hero 不加入此效果，以免和 3D Galaxy 競爭焦點。

### 頁面切換

- 單頁應用切換 `view` 後重新建立觀察目標。
- 新頁面頂端第一個主要區段可立即成為焦點，不等待額外使用者操作。

## 效能與無障礙

- 不使用持續性的 `scroll` 事件、模糊濾鏡或大面積 `backdrop-filter`。
- 動畫只改變偽元素 `opacity`，避免觸發布局或重繪大量內容。
- `prefers-reduced-motion: reduce` 時取消光暈淡入淡出，保留靜態明暗與星點。
- 內頁不新增 Canvas；既有首頁 Galaxy 的手機效能策略維持不變。

## 驗收標準

1. 首頁下半部、問卷、結果、行情與方法頁皆能看到克制的星點。
2. 捲動時，畫面中央主要區段在 700～900ms 內柔和亮起，前後區段回暗。
3. 任一時間最多只有一個主要區段帶有焦點光暈。
4. 文字、圖表、按鈕與表單的對比不低於修改前。
5. 桌面與手機沒有水平溢位，頁面切換後焦點狀態正常更新。
6. 減少動態模式下沒有光暈過渡動畫。
7. 瀏覽器主控台無 JavaScript 或 WebGL 錯誤。

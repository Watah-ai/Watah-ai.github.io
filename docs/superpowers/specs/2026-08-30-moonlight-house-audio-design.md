# 月光奏鳴曲與霓虹房屋控制設計規格

## 目標

將使用者提供的《月光奏鳴曲》MP3 整合為全站背景音樂。網站載入一秒後嘗試自動播放，並以固定於右下角的小房屋控制播放狀態：亮燈代表播放，關燈代表暫停。

## 音訊資源

- 原始檔案重新命名為 `moonlight-sonata.mp3`，放置於網站靜態資源目錄。
- 使用原生 `<audio>` 元素播放，不新增音訊函式庫。
- 設定循環播放與 25% 初始音量。
- 使用 `preload="metadata"`，避免進站時立即下載完整約 10.24 MB 音訊。
- 音訊元件位於全站應用根層級，切換首頁、問卷、結果、行情與方法頁時不中斷。

## 自動播放流程

1. 網站完成掛載後等待 1,000ms。
2. 呼叫 `audio.play()` 嘗試有聲自動播放。
3. 成功時將控制狀態設為播放，房屋亮燈。
4. 若瀏覽器阻擋自動播放，維持暫停狀態與關燈房屋，不顯示錯誤訊息。
5. 使用者首次點擊房屋後正常播放；此操作符合瀏覽器的使用者手勢要求。
6. 使用者手動暫停後，本次頁面工作階段不再自動重新播放。

## 房屋控制介面

- 固定於右下角，位於內容、Galaxy 與光暈效果上方，但不遮擋主要操作區。
- 使用 CSS 邊框、屋頂與窗戶建立房屋輪廓，不使用外部圖片或大型 SVG。
- 播放狀態：窗戶使用珊瑚橘與冷藍霓虹光，房屋輪廓提高亮度。
- 暫停狀態：窗戶關燈，輪廓改為低亮度藍灰色。
- 狀態切換只動畫小範圍的透明度、顏色與陰影，時間約 220ms。
- 桌面顯示小房屋與「月光奏鳴曲」短標籤；手機只顯示房屋。
- 按鈕提供動態 `aria-label`：「暫停月光奏鳴曲」或「播放月光奏鳴曲」。
- 鍵盤可操作，並沿用全站焦點框樣式。

## 狀態同步與錯誤處理

- 以 `<audio>` 的 `play`、`pause` 與 `ended` 事件同步 UI，不只依賴按鈕點擊推測狀態。
- 音訊載入失敗時房屋維持關燈，按鈕停用並以 `title` 說明音訊目前無法播放。
- 快速連續點擊時避免重複執行尚未完成的播放請求。
- 元件卸載時清除一秒計時器與事件監聽。

## 響應式與動態偏好

- 桌面控制區距離右側與底部約 20～24px。
- 手機距離邊緣約 14～16px，最小可點擊範圍維持 44×44px。
- `prefers-reduced-motion: reduce` 時取消燈光狀態過渡，但保留亮燈／關燈差異。
- 霓虹亮度不得形成大面積光暈或影響正文閱讀。

## 驗收標準

1. 網站載入一秒後確實呼叫播放；允許自動播放的瀏覽器會開始播放。
2. 自動播放被阻擋時不出現未處理錯誤，房屋維持關燈。
3. 點擊房屋可播放與暫停，燈光狀態與實際音訊一致。
4. 音樂在網站內頁切換時不中斷。
5. 音訊播放完畢後可無縫循環。
6. 桌面與手機都不遮擋主要按鈕或產生水平溢位。
7. 網站建置成功，瀏覽器主控台沒有 JavaScript 或音訊錯誤。

## 授權備註

樂曲本身屬公共領域，但提供的錄音版本授權未知。網站維持私人狀態時先完成整合；日後公開分享前需確認該錄音版本允許公開使用。

# 數字欄位零值輸入修正設計

## 問題

「適居分析」的安全購屋範圍使用受控數字欄位。使用者刪除全部內容時，空字串會立即轉成數字 `0`；接著輸入新數字時，瀏覽器可能把內容顯示成以零開頭的字串。

## 預期行為

- 刪光欄位內容後，欄位顯示 `0`。
- 當欄位目前為 `0` 時，使用者輸入的下一個有效數字直接取代 `0`。
- 例如目前為 `0`，輸入 `5` 後顯示並儲存為 `5`，不顯示 `05`。
- 原有最小值、最大值、小數步進與即時試算行為維持不變。
- 此規則套用至安全購屋範圍內所有共用 `NumericField` 欄位。

## 實作方式

在共用 `NumericField` 的輸入事件中區分空字串與數字字串：

1. 空字串立即寫入欄位允許的最低值；安全購屋金額欄位即為 `0`。
2. 非空字串只接受數字與一個小數點；不符合格式的輸入不會顯示。
3. 合法字串先移除多餘的整數前導零，再轉為數字。
4. 小於 1 的合法小數（例如 `0.5`）保留必要的 `0.`，不可轉成 `.5` 或 `5`。
5. 數值仍依欄位既有 `min`、`max` 範圍限制後寫入答案狀態。

欄位使用局部字串狀態保留 `0.` 等尚未完成的合法輸入，並同步更新數值答案。不改變 Answers 型別或 sessionStorage 格式。

## 驗證

- 欄位刪光後顯示 `0`。
- 從 `0` 輸入整數 `5`，結果為 `5`。
- 可輸入 `0.5`，且結果仍為 `0.5`。
- 原有上下限仍生效。
- 執行 lint 與 GitHub Pages 靜態建置。

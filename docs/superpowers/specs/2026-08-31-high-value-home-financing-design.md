# 高價住宅貸款限制與自備款上限設計

## 目標

讓首購試算在高額自備款情境下仍能正確輸入與保存數值，並在推估購屋總價達臺中高價住宅門檻時，自動套用現行最高三成貸款限制。

## 官方依據與定位

依中央銀行現行規定，臺中市屬臺北市、新北市以外地區；住宅鑑價或買賣金額孰低達 4,000 萬元者，屬高價住宅，貸款額度最高不得超過該基準的三成，且不得有寬限期。

網站沒有銀行鑑價，因此只能用試算購屋總價作初步門檻判斷。結果頁必須說明實際認定仍依銀行鑑價、買賣金額與個案核貸結果為準，不可宣稱試算即為可核貸額度。

## 輸入調整

- 「目前可用自備款」上限由 9,999 萬元提高為 999,999 萬元。
- 只有自備款欄位提高上限；預留資金、收入、債務、生活支出及其他數字欄位維持原上限。
- sessionStorage 答案清理邏輯同步接受最高 999,999 萬元，避免重新整理後被截回 9,999 萬元。
- 保留受限制字串輸入：`0.1` 可輸入、`0100` 正規化為 `100`、刪光回到 `0`，非數字內容不顯示。

## 預算公式

現有三段預算的月付能力公式維持不變。每一段先計算貸款本金能力 `L` 與可用現金 `C`，再依總價區間求最大可行房價：

1. 一般首購情境：最高貸款成數假設 80%，總價上限為 `min(L + C, C / 0.2)`。
2. 若一般情境上限未達 4,000 萬元，直接使用該結果。
3. 高價住宅情境：最高貸款成數 30%，總價上限為 `min(L + C, C / 0.7)`。
4. 若高價住宅情境上限達 4,000 萬元，使用該結果。
5. 若一般情境可達 4,000 萬元、但現金不足以符合高價住宅至少七成自備款，預算上限設為 3,999 萬元，避免顯示一個不符合三成貸款限制的 4,000 萬元結果。

所有結果仍以萬元整數顯示。推薦排序與 Hard Gate 繼續使用更新後的三段預算，不另建立第二套判斷。

## 結果頁說明

將固定的「最高貸款成數 80%」改為分段說明：

- 未滿 4,000 萬元採最高八成的首購情境假設。
- 達 4,000 萬元時套用臺中高價住宅最高三成、無寬限期限制。
- 本站以試算總價作初步判斷，實際以銀行鑑價或買賣金額孰低及銀行核貸為準。

## 驗證

- 自備款可輸入並保存 999,999 萬元，超過時限制於上限。
- 自備款重新整理後不會被截回 9,999 萬元。
- `0.1`、`0100`、空字串及非法文字維持既定輸入行為。
- 一般情境低於 4,000 萬元時公式與目前結果一致。
- 現金不足七成時，預算不會跨入 4,000 萬元門檻。
- 現金及月付能力足夠時，高價住宅總價以三成貸款限制計算。
- 執行 lint、TypeScript 與 GitHub Pages 靜態建置。

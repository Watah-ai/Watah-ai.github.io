# 好宅指南 Galaxy 首頁背景設計規格

## 1. 目標與範圍

在不改變版本 2 房市資料、推薦規則、問卷與結果功能的前提下，將首頁第一屏改為深色資料科技風，加入即時生成的 3D Galaxy 粒子背景。動畫只負責品牌氛圍與資料分析意象，不承擔互動操作，也不能阻擋「開始首購分析」主要流程。

本次包含首頁 Galaxy 背景、文字可讀性、裝置效能分級、減少動畫與 WebGL 失敗時的降級處理。問卷、結果、市場資料與方法頁維持既有淺色資訊介面。

本次不包含拖曳旋轉、縮放、GUI 控制面板、重設視角、暫停按鈕、全螢幕控制、影音素材或付費服務。

## 2. 視覺設計

首頁第一屏使用全版深黑與墨綠背景。Galaxy 位於畫面右半部，左半部保留標題、說明與主要行動按鈕。桌面版第一屏至少顯示：

- 好宅指南品牌與導覽列
- `TAICHUNG FIRST-HOME INTELLIGENCE` 輔助標示
- 「用資料找到適合你的第一間房」主標題
- 首購分析說明
- 「開始首購分析」主要按鈕
- 「查看資料方法」次要按鈕
- 13,050 筆住宅成交、28 個行政區、147 組房型樣本

Galaxy 由 4 條螺旋星臂、中央黑洞、橘紅色吸積盤、青綠與藍白色外圍粒子構成。中心亮而密集，外圍疏散並具有不規則偏移。畫面使用高對比但避免閃爍過強；深色漸層遮罩必須確保首頁文字在任何動畫畫格都可閱讀。

手機版保持相同品牌方向，但 Galaxy 置於中央偏上並降低亮度，文字與按鈕放在前景。首屏內容可自然向下延伸，不要求在單一手機高度內顯示所有統計數字。

## 3. 技術架構

### 3.1 元件邊界

- `GalaxyBackground`：建立 Three.js 場景、相機、渲染器、粒子幾何與逐幀動畫；不讀取房市資料，也不處理頁面導覽。
- `HeroSection`：承載首頁文字、按鈕、統計數字與深色遮罩；只透過背景元件的狀態得知動畫是否可用。
- `MainApp`：保留既有頁面切換與分析流程，將新版 Hero 作為首頁入口。

Galaxy 元件在卸載時必須取消動畫影格、解除事件監聽、釋放 BufferGeometry、Material、Texture 與 WebGLRenderer，避免重新進入首頁後累積 GPU 資源。

### 3.2 粒子生成

使用 Three.js、WebGL、`BufferGeometry` 與 GPU Points。粒子位置、顏色、尺寸、相位、角速度與隨機擾動以型別陣列存入 BufferAttribute。若標準 `PointsMaterial` 無法同時滿足圓形柔光、亮度閃爍及獨立粒子尺寸，改用精簡的自訂 GLSL Shader；不使用預先錄製影片。

星臂基礎角度由半徑、臂序號與螺旋程度計算，再加入半徑、角度與高度亂數。粒子中心密度高、厚度薄，外圍密度遞減並增加分散程度。中央保留不生成粒子的黑洞區，黑洞外建立高亮度橘紅吸積盤。

### 3.3 動畫

每個粒子依半徑取得不同角速度：內圈快、外圈慢。Shader 以時間、粒子相位與半徑計算角度推進、細微垂直漂移、閃爍與擾動，因此星系不會只是整體剛性旋轉。鏡頭從斜上方觀看完整星系，進行幅度很小的自動環繞，避免背景移動影響文字閱讀。

動畫採 `requestAnimationFrame`，並以 elapsed time 而非固定逐幀增量更新，使不同更新率裝置上的速度一致。頁面不可見時停止渲染，重新可見後恢復，避免背景分頁持續耗電。

## 4. 效能分級

粒子數量不是固定承諾，而是依裝置能力選擇安全上限：

| 裝置級別 | 粒子目標 | Pixel ratio 上限 |
| --- | ---: | ---: |
| 桌面高效能 | 90,000–100,000 | 1.75 |
| 桌面一般／平板 | 55,000–75,000 | 1.5 |
| 手機 | 25,000–40,000 | 1.25 |

偵測依據以視窗尺寸、觸控能力、裝置記憶體提示與渲染實測為輔助，不依賴單一 user-agent 字串。Canvas 只覆蓋首頁第一屏；避免高成本後處理、陰影、實體光源與每幀重建 BufferGeometry。

目標是在一般桌面裝置接近 60 FPS，在手機維持可操作的穩定流暢度。若連續觀察到明顯低幀率，允許降低渲染解析度或停用次要閃爍與鏡頭環繞，但不得影響網站按鈕與表單操作。

## 5. 無障礙與降級

- Canvas 設為裝飾性背景，不進入鍵盤焦點，也不向螢幕閱讀器重複描述。
- 遵守 `prefers-reduced-motion: reduce`：不啟動逐幀動畫，顯示靜態 Galaxy 畫格或深色漸層背景。
- WebGL 建立失敗、Shader 編譯失敗或裝置資源不足時，首頁自動切換為深色漸層與柔和放射光，不顯示阻斷式錯誤。
- 動畫層使用 `pointer-events: none`，所有導覽與按鈕保持可點擊。
- 文字與按鈕必須符合可讀對比，資訊不可只靠顏色傳達。

## 6. 資料與功能不變條件

Galaxy 改版不得更改：

- 115 年上半年台中實價資料與統計結果
- 負擔能力計算
- Hard Gate 與推薦排序
- 問卷欄位、結果內容與外部房仲平台入口
- 資料來源、授權與限制說明

首頁統計數字仍由既有資料物件取得，禁止在元件中另外硬編一組可能過期的數字。

## 7. 錯誤處理

- 初始化期間先顯示 CSS 深色背景，避免白畫面。
- Three.js 載入或建立場景失敗時記錄非敏感錯誤並使用 CSS 背景。
- 視窗尺寸為零或元件已卸載時不執行 resize 與 render。
- WebGL context lost 時停止動畫並顯示降級背景；不反覆自動重建造成當機循環。
- Galaxy 錯誤不得傳播到問卷或主應用程式，使首頁主要按鈕始終可用。

## 8. 驗收與測試

### 視覺驗收

- 首頁可看見完整螺旋 Galaxy、中央黑洞與橘紅吸積盤。
- 至少 4 條星臂可辨識，但粒子分布保持自然。
- 首頁文字在 Galaxy 最亮位置經過時仍清楚可讀。
- Galaxy 不覆蓋或阻擋任何按鈕。

### 功能驗收

- 「開始首購分析」可正常進入既有問卷。
- 「查看資料方法」與導覽列維持正常。
- 完成問卷後的推薦結果與版本 2 一致。
- 從其他頁面返回首頁不會出現重複 Canvas 或多重動畫迴圈。

### 瀏覽器與裝置驗收

- 桌面 Chrome／Edge 可正常顯示與調整視窗尺寸。
- Android Chrome 與 iOS Safari 可載入，旋轉螢幕後比例正確。
- 高 DPI 裝置受 pixel ratio 上限保護。
- 減少動態設定生效。
- WebGL 不可用時仍能閱讀首頁並開始分析。

### 工程驗收

- 正式建置成功，沒有 TypeScript 或 JavaScript 錯誤。
- 瀏覽器主控台沒有未處理例外、Shader 錯誤或持續累積警告。
- 動畫不會造成頁面水平或垂直捲軸異常。
- 手機採降低後的粒子數與 pixel ratio。
- Canvas 卸載後 GPU 與事件資源已釋放。

## 9. 發布方式

先在本機完成整合與桌面／手機瀏覽器驗證，再建立新的 Sites 版本。既有版本 2 保留為可回復基準；Galaxy 改版以新版本發布，不覆寫資料內容或推薦規則。

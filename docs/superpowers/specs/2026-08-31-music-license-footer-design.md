# 頁尾音樂授權標示設計

## 目標

在全站頁尾清楚標示背景音樂的作者與授權狀態，讓使用者不需操作播放器也能看見署名，以及 CC、PD 兩個授權標誌。

## 顯示內容

- 曲目：`Moonlight Sonata`
- 作者：`Paul Pitman`
- 授權：`Public Domain`
- 視覺標誌：兩個並列的圓形 `CC`、`PD` 標誌

標誌旁必須同時出現文字 `Public Domain`，不以圖示作為唯一的授權說明。作者姓名依使用者指定拼寫為 `Paul Pitman`。

## 介面配置

在現有全站頁尾內新增獨立的音樂署名列，與網站名稱及資料免責聲明分開。署名列包含曲目、作者、授權文字和 CC／PD 標誌。

桌面版採橫向排列；窄螢幕可自然換行，但兩個標誌保持並列且不可因版面縮小而消失。顏色與現有深色科技風頁尾一致，藍色標誌提供足夠對比，但不搶過主要內容。

## 實作邊界

- 使用站內 JSX 與 CSS／SVG 呈現標誌，不依賴外部圖片服務。
- 不變更音檔、播放行為、自動播放備援或播放器控制。
- 不新增分析事件、外部請求或使用者資料處理。
- 標誌應從輔助技術隱藏，完整授權意義由可讀文字提供。

## 驗證

- 執行 lint 與 GitHub Pages 靜態建置。
- 檢查桌面版及 390px 手機版頁尾，確認文字不溢出、標誌並列且可見。
- 確認播放器的播放、暫停與自動播放備援未受影響。
- 確認頁尾可見 `Paul Pitman`、`Public Domain`、`CC` 與 `PD`。

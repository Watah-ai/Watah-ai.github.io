# CIA 資安強化與公開發布設計

## 目標

在網站改為公開存取前，修正已識別的高風險依賴與防護缺口，採用隱私優先的瀏覽器資料策略，並以重新稽核結果作為公開發布門檻。

## 機密性（Confidentiality）

- 將問卷答案從 `localStorage` 改為 `sessionStorage`。
- 問卷資料只保留在目前分頁的瀏覽器工作階段；關閉分頁後由瀏覽器清除。
- 不新增伺服器資料庫、分析追蹤、帳號系統或問卷資料傳輸。
- 讀取工作階段資料時逐欄驗證，只接受網站定義的數字、布林、選項與陣列值；無效資料移除並回復安全預設值。

## 完整性（Integrity）

- 數字欄位在程式層檢查有限數值並限制於欄位的最小值與最大值，不只依賴瀏覽器 HTML 限制。
- 儲存資料的建物類型、通勤目的地、優先順序與巢狀結構必須符合既定允許清單。
- 無效或舊格式資料不進入預算與推薦計算。
- 保留現有政府成交資料、計算規則與推薦排序，不改動分析模型。

## 可用性（Availability）

- 將 Next.js 與受影響的正式依賴升級到沒有目前已知高風險公告的相容版本。
- 保留星系 WebGL 失敗備援、音樂自動播放備援、單一捲動與既有導覽。
- 升級後執行建置與主要分析流程檢查，若相容性或建置失敗則不得發布。

## HTTP 防護

全站回應加入並在正式部署驗證以下政策：

- `Content-Security-Policy`：預設只允許同源資源；禁止外掛物件、外部表單與第三方框架嵌入；允許網站現有的同源圖片、字型、音訊與必要的框架行內樣式／腳本。
- `X-Frame-Options: DENY` 與 CSP `frame-ancestors 'none'`：阻擋點擊劫持。
- `X-Content-Type-Options: nosniff`：阻擋 MIME 類型猜測。
- `Referrer-Policy: strict-origin-when-cross-origin`：限制跨站來源資訊。
- `Permissions-Policy`：停用網站未使用的相機、麥克風與定位權限。
- `Strict-Transport-Security`：要求瀏覽器持續使用 HTTPS，不宣告不屬於本站控制範圍的子網域。

## 公開發布門檻

公開前必須同時通過：

1. 正式依賴漏洞掃描沒有 P0 或 P1。
2. 專案建置成功。
3. 正式部署的首頁回應含預期安全標頭。
4. 問卷資料只存在 `sessionStorage`，且無效資料會安全回復。
5. 首頁、問卷、結果、行情、方法頁、星系與音樂功能沒有阻斷性錯誤。

通過後才把 Sites 存取模式改成「網際網路上的任何人」。若任一門檻未通過，網站維持私人狀態並回報阻擋原因。

## 網址與託管

- 本次不遷移到 GitHub Pages 或 Google Sites。
- 保留目前 ChatGPT Sites 部署，以降低遷移造成的功能與安全風險。
- 沒有自有網域時使用 Sites 產生的預設網址；帳號命名空間不在本次可修改的網站 slug 範圍。
- 未來購買網域後，可透過 Sites 自訂網域功能綁定，不需重寫網站。

## 範圍外

- 購買網域或建立第三方託管帳號。
- 遷移到 GitHub Pages、Google Sites 或其他平台。
- 新增登入、後端儲存、分析追蹤或資料蒐集。
- 修改房市資料、計算公式、視覺主題或既有功能內容。

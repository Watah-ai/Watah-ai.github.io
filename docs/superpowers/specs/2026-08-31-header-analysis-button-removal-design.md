# 導覽列重複分析按鈕移除設計

## 目標

移除網站頁首右上角的「開始分析」按鈕，避免它與桌面主導覽中的「適居分析」功能重複，同時維持導覽列的視覺平衡與既有分析入口。

## 版面與行為

- 從全站頁首移除右上角「開始分析」按鈕及其互動。
- 桌面版保留「適居分析」、「台中行情」與「方法與資料」三項主導覽，並讓導覽群組在頁首水平置中，不因右側按鈕消失而偏移。
- 行動版原本隱藏主導覽；移除右側按鈕後只保留左側品牌標誌，不加入空白佔位元素或替代按鈕。
- 首頁主視覺中的「開始首購分析」仍保留，繼續作為首頁的主要分析入口。
- 「適居分析」仍直接進入問卷，分析流程、結果頁與目前資料狀態管理不變。

## 實作範圍

- 僅調整 `MainApp` 的頁首結構與必要的響應式排列樣式。
- 不修改首頁主視覺、星系、音樂、自動播放備援、捲動效果、行情、方法頁或推薦邏輯。

## 驗收條件

1. 全站頁首不再顯示「開始分析」。
2. 桌面版三項主導覽保持水平置中且可正常切換頁面。
3. 行動版頁首只顯示品牌標誌，沒有多餘空白按鈕或水平溢位。
4. 首頁「開始首購分析」與主導覽「適居分析」仍可啟動分析流程。
5. 專案建置成功，既有音樂、單一捲動與分析功能不受影響。

## 範圍外

- 更名或重新排序主導覽。
- 新增漢堡選單或其他行動版導覽。
- 改動分析流程、內容或視覺主題。

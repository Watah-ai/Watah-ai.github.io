# 音樂音量與單一捲動修正設計

## 目標

改善背景音樂過小與頁面出現兩個垂直捲動軸的問題，同時維持目前的月光科技配色、星系動畫、霓虹小屋控制與各分析頁面功能。

## 音樂音量

- 將背景音樂預設音量從 25% 提升至 55%。
- 保留進站一秒後自動嘗試播放的行為。
- 若瀏覽器阻擋有聲自動播放，仍於第一次點擊、觸碰或按鍵時啟動。
- 霓虹小屋繼續負責播放、暫停與狀態提示。
- 本次不新增音量滑桿，避免擴大介面與互動範圍。

## 捲動修正

- 現況主內容容器使用水平隱藏溢位；依 CSS 溢位計算規則，垂直方向會成為可捲動容器，並與文件根層捲動重疊。
- 將主內容的水平溢位改為裁切模式，只裁掉星系及全寬光暈造成的水平超出，不建立新的垂直捲動容器。
- 整個網站只保留瀏覽器文件層的垂直捲動。
- 不改動星系位置、全寬光暈、固定音樂控制或各頁內容高度。

## 驗收條件

1. 音訊元素初始音量為 0.55。
2. 瀏覽器允許時，進站一秒後開始播放；阻擋時，第一次有效互動後開始播放。
3. 霓虹小屋可以暫停並重新播放。
4. 主內容容器不再是垂直捲動容器。
5. 桌面與手機畫面只顯示一條垂直捲動軸。
6. 星系與光暈不造成水平捲動。
7. 專案建置與程式檢查沒有新增錯誤。

## 範圍外

- 音量滑桿與音量偏好儲存。
- 更換音樂、剪輯音檔或加入播放清單。
- 修改頁面內容、分析規則、配色或星系動畫。

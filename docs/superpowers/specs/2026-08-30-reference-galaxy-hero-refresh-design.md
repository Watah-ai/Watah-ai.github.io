# 附件風格 Galaxy 首頁改版規格

## 目標

將首頁現有 Galaxy 背景調整為附件中的螺旋星系風格：高密度藍紫色星臂、明亮金色核心與黑色深空。星系持續緩慢旋轉，但不提供互動控制。

## 保留內容

- 保留首頁既有導覽列。
- 保留「用資料找到適合你的第一間房」主標題、說明文字、統計資料與行動按鈕。
- 保留現有台中首購分析、需求推薦與其他頁面功能。

## 不加入內容

- 不加入附件右側的 `SPIRAL GALAXY` 控制面板。
- 不加入密度、旋臂數量、速度滑桿。
- 不加入附件底部的拖曳、縮放操作提示。
- 不加入滑鼠或觸控旋轉、縮放功能。

## 視覺設計

- 使用四條清楚但自然分散的螺旋星臂。
- 中央核心採白金、亮黃與橘色，外圈漸變為白、電光藍、靛藍及紫色。
- 增加高亮星點、稀疏暖色星點與深空背景星點，呈現附件的高密度、電影感效果。
- 鏡頭使用接近正面、略帶傾斜的角度，使完整橢圓星系在首頁右側至中央清楚可見。
- 以遮罩與暗色漸層維持左側網站文案可讀性。
- 手機版縮小並重新置中星系，避免核心被文字完全遮住。

## 動畫與效能

- 星臂粒子以不同角速度繞核心運動，視覺上形成持續緩慢旋轉，而不是整張圖片旋轉。
- 保留細微閃爍與流動，整體速度降低，避免干擾網站內容。
- 桌機維持較高粒子數；手機降低粒子數與裝置像素比。
- 使用者啟用減少動態效果時只渲染靜態畫面。
- WebGL 無法使用時顯示同色系靜態漸層背景，網站功能仍可操作。

## 驗收標準

1. 首頁星系外觀明顯接近附件的藍紫四旋臂與金色核心。
2. 星系可以持續、緩慢且流暢地旋轉。
3. 畫面沒有附件中的控制面板、英文標題或操作提示。
4. 原有首頁文字、按鈕與首購分析流程均可正常使用。
5. 桌機與手機沒有水平溢出，WebGL 與 JavaScript 沒有阻斷錯誤。

# VISTA.IO × Galaxy 全站整合設計規格

本規格取代同日的單一 Galaxy 首頁改版規格，作為下一版全站視覺實作依據。

## 設計目標

將「好宅指南｜台中首購適居分析」全站改造成深色科技數據平台。視覺語言參考 VISTA.IO 範本的黑色背景、等寬大標、珊瑚橘操作色、米白文字、深灰浮層與大量留白；內容、品牌、資料與互動仍屬於好宅指南，不複製範本的商標、英文文案、影片或其他資產。

首頁同時採用已確認的 Galaxy 主視覺：藍紫四旋臂、金色核心、緩慢旋轉，不提供控制面板或操作提示。

## 全站設計系統

### 色彩

- 主背景：近黑色 `#050706`。
- 次背景：深灰綠 `#171B18`，用於導覽列、表單與分析面板。
- 邊線：低對比灰綠 `#303731`。
- 主文字：帶綠的米白 `#EDF2E6`。
- 次文字：灰綠 `#9CA79E`。
- 主要操作色：珊瑚橘 `#FF624A`。
- 次要數據色：淺薄荷 `#BFD8C5`。
- 藍紫色只保留給 Galaxy 與少量圖表輔助，不與主要按鈕競爭。

### 字體與層級

- 品牌、頁面標題、數據數字與按鈕使用等寬字體語氣；中文字使用系統等寬字體後備。
- 內文使用清晰的無襯線字體，避免長篇中文全部等寬而降低閱讀性。
- 首頁標題採大型、錯位或分欄排列，重現 VISTA.IO 的實驗性科技感。
- 英文眉題使用全大寫、寬字距；中文內容維持自然字距。

### 版面與元件

- 桌機內容最大寬度維持約 1152px，使用大留白與 1px 分隔線建立節奏。
- 卡片由目前的大量白色圓角卡改為深色面板、小幅圓角與細邊框。
- 主要按鈕為珊瑚橘實心矩形；次要按鈕為深色透明底與細框。
- 數據、進度與圖表使用珊瑚橘、薄荷綠與米白三色，不只依靠顏色傳達狀態。
- 動畫只使用在 Galaxy、按鈕與展開面板的輕微轉場，不加入干擾分析閱讀的大幅動效。

## 頁面設計

### 全站導覽

- 導覽列全站保持黑色科技風，不再因頁面切換回到米白背景。
- 品牌名稱保留「好宅指南／台中首購」，重點字改為珊瑚橘。
- 桌機導覽採深灰浮層排列；手機維持精簡導覽與主要分析按鈕。
- 目前頁面使用珊瑚橘底線、文字或邊框共同表示，不只用色彩。

### 首頁

- 第一屏為滿版 Galaxy：四條藍紫星臂、金白核心與黑色星空，星系持續緩慢旋轉。
- 左側保留「用資料找到適合你的第一間房」、說明、開始分析與範例報告按鈕。
- 標題改為 VISTA.IO 式分段大字與不對稱留白，但不可遮擋 Galaxy 核心。
- 不加入附件的 `SPIRAL GALAXY` 標題、控制面板、滑桿或操作提示。
- 成交筆數、行政區與房型組合改為大數字統計帶，使用細線區隔。
- 後續流程區改為黑色模組化敘事，步驟編號採珊瑚橘大字。

### 首購問卷

- 問卷使用置中的深色資料終端面板，頂部顯示等寬步驟標籤與珊瑚橘進度條。
- 數字輸入、選項與滑桿全部改為深色表面；選取狀態同時顯示珊瑚橘邊框與勾選標記。
- 錯誤、限制與可信度提示使用有標題的低彩度提示框，維持可讀性。
- 五步資料結構、驗證規則與本機保存方式不變。

### 推薦結果

- 預算三段改為深色數據卡，數字採大型等寬字體；安全、中性與高風險透過標籤和說明共同表達。
- 推薦排名改為可展開的深色分析列：左側分數、中央房型與價格、右側展開操作。
- 適配度長條、理由、犧牲、成交樣本與外部搜尋條件都保留，改用統一深色資料視覺。
- 591 與樂屋網連結維持原功能，外部連結有清楚標示。
- 無結果狀態使用珊瑚橘細框與可操作的返回按鈕，不以亮色大面積警示。

### 台中行情

- 行政區單價長條圖改為黑底橫向數據圖，珊瑚橘表示數值、米白顯示數字、灰綠顯示基準線。
- 住宅成交筆數與閱讀說明改為側邊深色資訊面板。
- 保留所有行政區、成交樣本、資料期間與中位數邏輯。

### 方法與資料

- 方法段落使用細線分隔的編號章節，減少卡片堆疊。
- 資料來源區使用深灰資料表格語言，突出資料集、期間、來源與授權。
- 政府資料集按鈕使用珊瑚橘主要操作樣式。
- 尚未接入資料的限制說明保留並提高辨識度。

### 頁尾

- 頁尾使用純黑底、細線與小型等寬文字，保留企業專題與免責聲明。

## 元件與資料邊界

- `GalaxyBackground` 只負責 WebGL 星系渲染、效能分級、視窗調整與資源清理。
- `MainApp` 只負責頁面切換、全站導覽與首頁組裝。
- `Questionnaire`、`Results`、`MarketDashboard`、`MethodPage` 的資料介面及計算流程不變，只調整展示層。
- 推薦演算法、公開資料 JSON、使用者答案與本機儲存格式不變，避免視覺改版影響分析結果。

## 響應式與可及性

- 手機降低 Galaxy 粒子數與像素比，重新定位核心，確保文字與按鈕不被遮擋。
- 桌機保留不對稱 VISTA.IO 構圖；手機改為單欄並縮短大型標題。
- 所有互動元件具備可見鍵盤焦點、足夠對比與觸控尺寸。
- 展開狀態、選取狀態與錯誤狀態都使用文字或圖示輔助，不只靠顏色。
- `prefers-reduced-motion` 時 Galaxy 靜止，其他轉場降至最低。

## 降級與錯誤處理

- WebGL 無法啟動時，以黑色、藍紫與金色的靜態漸層背景替代，首頁內容與分析功能仍可使用。
- Galaxy 載入期間不顯示大型載入文字，使用原生深色背景避免畫面跳動。
- 不新增付費服務、授權素材或需要 API 金鑰的功能。

## 驗收標準

1. 全站所有頁面一致呈現 VISTA.IO 式黑色科技數據風格。
2. 首頁 Galaxy 接近附件的藍紫四旋臂與金色亮核心，並緩慢流暢旋轉。
3. 不出現附件的控制面板、英文標題或操作提示。
4. 問卷五步、輸入驗證、推薦展開、情境分析、市場圖表與外部房源連結均可使用。
5. 原有推薦結果與資料統計在改版前後一致。
6. 桌機與手機無水平溢出，文字對比與鍵盤操作符合基本可及性要求。
7. 建置成功，瀏覽器沒有阻斷性的 JavaScript 或 WebGL 錯誤。

## 發布後首頁可讀性調整

- 首頁說明文字使用接近米白的高對比文字，並放在不透明度較高的深色遮罩上，避免金色核心與白色粒子穿過字形；遮罩不用模糊濾鏡，以免增加 WebGL 合成成本。
- Galaxy 粒子角速度降至目前約一半，保留差速旋轉與閃爍，不改成整張圖片旋轉。
- Galaxy 群組中心往右上方移動，桌機目標落在「第一間房」文字右側；手機仍使用既有縮放與遮罩，避免壓住標題和主要按鈕。
- 驗收使用接近回饋截圖的 812×792 視窗，確認說明文字完整可讀，Galaxy 核心不再位於文字段落正後方。
